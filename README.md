# Coffee Shop Composition Demo

A Dart console application demonstrating object composition through a simple coffee shop simulation.

---

## How to Run
```bash
dart run lib/main.dart
Output Legend
```

LEGEND

CoffeeShop	Container and integration actions
CoffeeMaker	Coffee-making process
CashRegister	Payment and transaction handling
InventoryCounter	Inventory management
